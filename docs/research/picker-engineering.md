# Picker and editor engineering

Five independent research briefs covered hit testing, durable identity, CSS/text ownership, Hide/restoration, and verification. Official browser specifications and upstream source informed the study. Research claims are hypotheses until code inspection and disposable-browser experiments establish them. Temporary checkouts were deleted after their revisions were recorded; no upstream project scripts were run.

## Decisions and evidence

| Concern                          | Mechanism                                                                                                                                                                            | Taylr decision                                                                                                                                                                                      |
| -------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Choosing a component             | Pointer events identify a rendered hit; semantic controls often contain SVG/text descendants. DOM ancestry, the composed event path and painted geometry answer different questions. | Keep control promotion, explicit Parent/Child refinement and trusted event suppression. Do not infer arbitrary framework components or promise canvas internals.                                    |
| Stable identity                  | A selector can be unique today and match another item after reordering or navigation. Framework keys are not necessarily exposed DOM identifiers.                                    | Prefer semantic item attributes and content links, preserve content query parameters, and verify the same declared identity on revisit. Structural fallbacks remain a documented limitation.        |
| Drafts versus persistence        | Author styles cannot reliably override USER-origin important declarations. Replacing durable CSS requires an asynchronous extension call.                                            | Keep local feedback plus serialized USER stylesheet replacement. Distinguish storage success from rendering failure; do not claim synchronous paint under every cascade.                            |
| Hide versus legacy display edits | Important declarations in a layer outrank unlayered important edits, regardless of selector specificity.                                                                             | Isolate Hide in a visibility layer. Removing Hide reveals the saved appearance rather than deleting that appearance.                                                                                |
| Text ownership                   | Assigning an element’s `textContent` replaces its children, including text fragments and comments retained by frameworks.                                                            | Edit existing text nodes in place, retain each original fragment, and restore only matching node identities and editor-owned values. Adopt site replacements instead of overwriting them on Cancel. |
| Storage pressure                 | The quota covers the entire storage area, including previews for other origins. Dropping only the newest picture may free nothing.                                                   | Retry without the new preview, then evict optional previews from Taylr profiles in that same area on quota failure. Preserve rules, pause state and other storage areas.                            |
| Diagnostics                      | A deadline releases the caller; it does not cancel an underlying protocol operation.                                                                                                 | Bound capture and detach separately, close late-attaching sessions, and retain the original failure when optional diagnostics fail.                                                                 |
| Controls                         | A CSS declaration is useful to the engine but seldom a good everyday input format.                                                                                                   | Use sliders, steppers and labeled choices. Advanced holds occasional size/spacing controls. Offer gaps only for existing flex/grid layouts; retain saved layout compatibility.                      |

Primary references: [DOM text content](https://dom.spec.whatwg.org/#dom-node-textcontent), [CSS cascade order and important layers](https://drafts.csswg.org/css-cascade-5/#cascade-sort), [Chrome scripting](https://developer.chrome.com/docs/extensions/reference/api/scripting), [Chrome storage](https://developer.chrome.com/docs/extensions/reference/api/storage), [CSSOM resolved values](https://drafts.csswg.org/cssom/#resolved-values), [HTML focus](https://html.spec.whatwg.org/multipage/interaction.html#focus), and [Playwright actionability](https://playwright.dev/docs/actionability).

## Failure-first experiments

- Text fragments/comments must remain the same nodes through preview and Cancel. A site replacement with the same visible text becomes the new baseline.
- A more specific saved display edit must not defeat Hide, including after a later edit Save. Removing Hide must reveal the remaining edit.
- Fill Chrome’s actual local quota with valid-size previews on another origin. Hide must commit both with and without a new capture, preserving all rules and leaving session/sync storage untouched.
- Reorder cards with a shared author link and a later unique permalink. Preserve the intended card, nearest nested link, and hierarchy through boxless wrappers.
- Keep site-owned accessibility and scrolling intact while a Select menu opens; Escape restores its trigger. A locked draft survives page keyboard input and rejected cross-tab Save.
- Type decimal and negative numbers one character at a time. The caret draft must survive incomplete punctuation, and units must not require CSS syntax.
- Close the page after CDP attach and stall screenshot delivery. Capture must classify the failure, settle within its budget and detach its session.
- Public component contracts exercise every exposed property, eligible text, hierarchy, invalid CSS, Reset/Cancel, controls, Save/Undo, Hide, reload/new-tab replay, Pause/Resume and Restore. Applicability is recorded per component.

## Boundaries and rejected conclusions

Shadow-root and iframe interiors, pseudo-elements and canvas internals remain separate future capabilities. Do not add a page-wide shadow registry, framework-internal hooks, arbitrary scripts or a new selector language merely to resemble DevTools. Upstream tools operate with different privileges and persistence goals.

Some independent claims were incorrect or unproven: the font allowlist does accept commas; `Promise.race` installs rejection handlers on its inputs; fixture routing and synthetic input rejection can explain failures without a product regression; native Select interaction must be tested with trusted input. A potentially disconnected response callback does not prove the background queue wedges. These need concrete browser evidence before a repair.

Used-size constraints such as `min-width`, flex sizing and native widget rendering must be separated from declaration acceptance. An empty app root is a readiness failure, not permission to substitute a different target. Initial application URL normalization must be observed before interaction while exact post-interaction navigation checks remain strict.

The upstream revisions and license comparison are in [element editing research](element-editing.md). Session reports and traces belong in generated evidence, not evergreen product documentation.
