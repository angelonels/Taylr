# Taylr interface intent

Product register. The work pattern is Operate: the website is the canvas and Taylr provides a small temporary instrument. Calm and precise, with one sage accent for the active tool, neutral surfaces that follow system appearance, system typography, and a restrained wordmark. The side panel explains the action, site scope, and saved state. The tool strip keeps Undo and Done beside the work. Avoid metaphor-heavy labels, decorative dashboards, particle effects, gratuitous springs, and blocking confirmations for reversible edits.
