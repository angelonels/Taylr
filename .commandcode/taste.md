# Taylr interface intent

A floating browser instrument, not a second page. The toolbar must preserve the website's viewport and stay movable. Smoked obsidian glass, a folded ribbon T, iris primary actions and coral selection feedback distinguish Taylr from unpredictable page colors. A dark isolation ring and inset specular rim give the material depth. Use a solid surface for reduced transparency/high contrast. Keep controls operational: Hide, Undo, Rules, Restore, Cancel/Done, Close; no marketing, taglines, or future tools.

React/TypeScript and Tailwind render the dock only when invoked. The framework-free controller restores rules on visits. Motion owns interruptible drag values/springs; short CSS transitions handle presses and disclosures. Keyboard selection is immediate, reduced motion removes travel, and hiding never waits for a disappearance animation. Visible exit controls and Escape must always work. Rule cards show actual locally captured component previews, never invented facsimiles.

Testing uses disposable Playwright Chromium. The catalog covers multiple distinct component types per site, selected for difficult DOM and interaction behavior. Website count alone is not coverage.
